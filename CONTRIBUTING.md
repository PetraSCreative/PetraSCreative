# Contributing to PetraSCreative

Thank you for your interest in contributing! This document provides guidelines for contributing to the project.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR-USERNAME/PetraSCreative.git`
3. Create a feature branch: `git checkout -b feature/your-feature-name`
4. Install dependencies: `npm install`
5. Start development: `npm run dev`

## Commit Guidelines

- Use clear, descriptive commit messages
- Format: `type(scope): description`
- Types: `feat`, `fix`, `docs`, `style`, `refactor`, `test`, `chore`
- Example: `feat(video-generation): add Synthesia API integration`

## Code Style

- Use TypeScript
- Follow ESLint and Prettier configurations
- Run `npm run lint` before submitting PR

## Testing

- Write tests for new features
- Run `npm test` to validate
- Maintain >80% code coverage

## Pull Request Process

1. Update README if needed
2. Add/update tests
3. Ensure all tests pass
4. Submit PR with clear description
5. Address review comments

## Reporting Issues

- Use GitHub Issues
- Provide clear description, steps to reproduce, and expected behavior
- Include screenshots/error logs if applicable

## Questions?

Open a discussion or reach out to the maintainers.
